# Portfolio Holdings (as of Jan 1, 2026)

Copy this file to `$MANGO_HOME/portfolio-holdings.md` (default
`~/.mango/portfolio-holdings.md`) and replace the rows with your own.

Each `##` heading starts an account. Anything in parentheses after the account
name is stripped, so `## Brokerage (1234)` groups as `Brokerage` — handy if you
want an account number visible locally without it appearing in tool output.

The header row must contain these columns; extra columns are ignored.
